A Java-based file utility tool that allows packing multiple files into a single archive and unpacking them back with all metadata preserved.
To enhance security, the packed file is encrypted, and only authorized users can decrypt and extract the data.
The project also features a Swing-based GUI for easy and user-friendly interaction.

🚀 Features

1.File Packing – Combines multiple regular files into a single archive.

2.File Unpacking – Restores original files and metadata from the packed archive.

3.Encryption – Built-in XOR-based encryption & decryption for data security.

4.Graphical User Interface (GUI) – Simple Swing-based UI for packing/unpacking.

5.ross-Platform – Works on any system with Java Runtime Environment (JRE).
